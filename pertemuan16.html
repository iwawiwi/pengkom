Pertemuan 16: Ujian Akhir Semester (UAS)

Selamat Datang di UAS

Ini adalah pertemuan terakhir sekaligus Ujian Akhir Semester mata kuliah Pengenalan Komputasi.

  • Format: Computer Based Test (CBT)
  • Materi: Seluruh materi perkuliahan (P1–P14)
  • Sifat: Closed Book — tanpa catatan/internet
  • Durasi: Sesuai jadwal UAS resmi

Tata Tertib UAS CBT

Dilarang

  • Membuka tab/aplikasi lain selama ujian
  • Berkomunikasi dengan peserta lain
  • Menggunakan handphone/perangkat lain
  • Meninggalkan ruangan tanpa izin pengawas

Wajib

  • Login ke sistem CBT sebelum waktu mulai
  • Bawa kartu identitas mahasiswa
  • Submit jawaban sebelum waktu habis
  • Tetap tenang dan kerjakan sendiri

Cakupan Materi UAS

Materi Pra-UTS (P1–P8)
  • Dasar Python, Variabel, Tipe Data
  • Percabangan (if/elif/else)
  • Perulangan (for/while)
  • List & Struktur Data Dasar
Materi Pasca-UTS (P9–P14)
  • Fungsi (def, return, scope)
  • Manipulasi String
  • Library (math, random, pandas)
  • Visualisasi Data (Matplotlib)
  • File CSV & Pandas

Petunjuk Teknis CBT

  1. Buka browser dan akses URL sistem CBT yang diberikan pengawas.
  2. Login menggunakan NIM dan password yang telah dibagikan.
  3. Pilih mata ujian Pengenalan Komputasi.
  4. Baca petunjuk soal dengan teliti sebelum mengerjakan.
  5. Klik Submit setelah semua soal selesai dijawab.
  6. Tunggu konfirmasi dari pengawas sebelum menutup browser.

Perjalanan Kita Bersama

  • P1–P2: Dasar Python
  • P3–P4: Percabangan
  • P5: Perulangan
  • P6: List
  • P7: Quiz 1
  • P8: UTS
  • P9: Fungsi
  • P10: String
  • P11: Library
  • P12: Visualisasi
  • P13: CSV & Pandas
  • P14: Review | P15: Quiz Pra-UAS

Selamat Mengerjakan!

Kerjakan dengan jujur dan percaya diri. Semoga hasil yang diperoleh mencerminkan usaha terbaik kalian.
