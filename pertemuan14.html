P9 — Fungsi: Konsep Kunci

  • Didefinisikan dengan def nama(param):
  • Dapat menerima satu atau lebih parameter
  • Mengembalikan nilai dengan return
  • Dapat dipanggil berulang kali tanpa menulis ulang kode
  • Membantu memecah masalah besar menjadi bagian kecil (modularisasi)

P9 — Fungsi: Scope Variabel

  • Lokal: variabel yang dibuat di dalam fungsi, hanya ada di sana
  • Global: variabel di luar fungsi, bisa dibaca dari dalam fungsi
  • Untuk mengubah variabel global dari dalam fungsi, gunakan kata kunci global
  • Hindari penggunaan global berlebihan — lebih baik gunakan return

P9 — Fungsi: Contoh Kode


def hitung_luas(panjang, lebar):
    luas = panjang * lebar
    return luas

hasil = hitung_luas(5, 3)
print(f"L: {hasil}")  # L: 15

def konversi_suhu(celsius):
    hasil = (celsius * 9/5) + 32
    return hasil

print(konversi_suhu(100))  # 212.0
                        

x = 10  # Variabel Global

def tambah(y):
    hasil = x + y
    return hasil

print(tambah(5))   # 15

def reset():
    global x
    x = 0

reset()
print(x)  # 0

P10 — String: Slicing & F-String

  • Index dimulai dari 0 — karakter pertama ada di index 0
  • Slicing: teks[start:end] — karakter ke-end tidak ikut
  • Index negatif: teks[-1] = karakter terakhir
  • F-string: f"Nilai: {x:.2f}" — format angka desimal
  • .startswith(s) / .endswith(s) → kembalikan True/False

P11 — Ringkasan Library

  • Konsep: library = kumpulan fungsi siap pakai (don't reinvent the wheel)
  • Import: import x (pemanggilan sesuai nama library), import x as y (alias), from x import z (import spesifik)
  • Standard library: math, random
  • External library: pandas untuk data tabular

P11 — Cakupan Utama

math & random

  • sqrt, pow, pi, ceil/floor
  • Trigonometri: sin, cos, radians
  • Acak: randint, choice
  • seed() untuk hasil acak konsisten

pandas (Intro)

  • pd.DataFrame(data) membuat tabel
  • Struktur: baris, kolom, index
  • Cek awal: head(), shape
  • Akses data: df['Nama']

P12 — Alur Matplotlib

  • 1) Import matplotlib.pyplot as plt
  • 2) Siapkan data
  • 3) Pilih plot (plot/bar/scatter/pie)
  • 4) Tambahkan title, xlabel, ylabel, legend/grid
  • 5) Tampilkan plt.show() atau simpan plt.savefig()

P12 — Contoh Ringkas

import matplotlib.pyplot as plt

# Persiapan data
bulan = [1, 2, 3, 4, 5, 6]
penjualan = [10, 20, 25, 30, 50, 45]

plt.plot(bulan, penjualan, marker='o')
# Beri judul dan label sumbu
plt.title("Grafik Penjualan")
plt.xlabel("Bulan")
plt.ylabel("Penjualan")
# Tambahkan grid
plt.grid(True)
# Tampilkan plot
plt.show()

P13 — Alur Kerja CSV

  • Baca file: pd.read_csv()
  • Inspeksi awal: head(), info(), describe()
  • Cleaning: isnull(), dropna(), fillna(), drop_duplicates()
  • Manipulasi: filtering & sorting
  • Simpan kembali hasil: to_csv()

P13 — Filtering & Sorting

Filtering

  • df[df['Umur'] > 20]
  • df[df['Kota'] == 'Jakarta']
  • (kondisi1) & (kondisi2) untuk AND
  • (kondisi1) | (kondisi2) untuk OR

Sorting & Output

  • sort_values('Umur') (ascending)
  • sort_values('Umur', ascending=False)
  • sort_values(['Kota', 'Umur'])
  • to_csv('hasil.csv', index=False)

P13 — Contoh Ringkas

import pandas as pd

# Baca data dari CSV
df = pd.read_csv('mahasiswa.csv')
print(df.head())
# Cek data yang kosong
print(df.isnull().sum())

# Hapus baris dengan nilai kosong
df = df.dropna()
# Hapus duplikat
df = df.drop_duplicates()
# filter umur diatas 20
senior = df[df['Umur'] > 20]
# Urutkan dari yang tertua
df_desc = df.sort_values('Umur', ascending=False)
# Tampilkan 5 data pertama setelah diurutkan
print(df_desc.head())

Contoh Program Lengkap


import pandas as pd
import matplotlib.pyplot as plt

# 1. Baca CSV (P13)
df = pd.read_csv('nilai_mhs.csv')
df = df.dropna()                           # Data Cleaning

# 2. Hitung rata-rata nilai (P9)
def hitung_rata_rata(kolom):
    return kolom.mean()

# 3. Jalankan fungsi
rata_rata = hitung_rata_rata(df['Nilai'])

# 4. Format output dengan f-string (P10)
print(f"Rata-rata : {rata_rata:.2f}")

# 5. Visualisasi (P12)
plt.bar(df['Nama'], df['Nilai'], color='steelblue')
plt.title("Nilai Mahasiswa")
plt.xticks(rotation=45)
plt.tight_layout()
plt.savefig("grafik_nilai.png")
plt.show()
